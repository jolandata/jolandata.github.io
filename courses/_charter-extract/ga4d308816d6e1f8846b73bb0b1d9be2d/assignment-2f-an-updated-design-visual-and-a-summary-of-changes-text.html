6. User Experience and Design Integration

Exercise: User-Centered Design

Steps:

1. Update Design:
   - Based on the feedback from your usability test, make necessary changes to your prototype.
   - Use the same tool you used for the initial prototype (Figma, Sketch, Adobe XD).

2. Summary of Changes:
   - Open a word processor.
   - Write a 200-word summary explaining how user feedback influenced your design changes. Example format:
     - Original Design: [Brief description]
     - Feedback Received: [Key points from user feedback]
     - Design Changes: [What changes did you make and why?]

Deliverable: An updated design (visual) and a summary of changes (text).
